## How I approach engineering

- Model business rules before implementing endpoints.
- Keep critical logic testable and separate from transport code.
- Make API contracts clear for frontend and other consumers.
- Document architecture, limitations, and setup steps.
- Keep source-backed data processing separate from generative responses.
- Prefer working demonstrations and verifiable tests over feature lists.
